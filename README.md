# OC Transpo Line 2 Trip Finder

## Instruction
1. Unzip Team13_A4_Source.zip
2. Double-click index.html to open the application directly in the browser

## Software & Dependencies
- A web browser.

## Where to Begin the Selected Task
- Begin on index.html and click Trip Finder.
- Main Task Walkthrough:
  1. Enter From: Mooney's Bay and To: Bayview (using the dropdown suggestions or typing directly).
  2. Keep Travel date: December 15, 2026 selected, enter Departure time: 14:30, and click Search for trip.
  3. Review the departures around 14:30, click a row or Open Line 2 schedule, select a departure time, and click Confirm journey.
